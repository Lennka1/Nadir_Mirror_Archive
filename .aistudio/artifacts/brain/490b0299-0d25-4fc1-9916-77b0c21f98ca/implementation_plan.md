# План реализации полу-РП и атмосферных модулей терминала

## 1. Обзор и концепция
Терминал архива работает как внутриигровой полу-РП инструмент оперативника: вся сюжетная информация раскрывается непосредственно на игровых сессиях, а сам сайт служит рабочей станцией для фиксации находок и создания ретро-атмосферы ЭЛТ-монитора без каких-либо сюжетных спойлеров.

В рамках обновления будут добавлены три компонента:
1. **Личный бортовой журнал улик и рапортов (`ЛИЧНЫЙ ЖУРНАЛ` / `NOTES`)** — оперативный модуль для ведения заметок игроками на сессиях и между ними.
2. **Тумблер цвета люминофора монитора (`P1 ЗЕЛЁНЫЙ` / `P3 ЯНТАРНЫЙ`)** — аппаратное переключение цветовой схемы ЭЛТ-экрана.
3. **Режим ожидания терминала с помехами (`STANDBY`)** — автоматический и ручной спящий режим монитора при бездействии с эффектом развёртки и редких радиопомех.

## 2. Детализация функционала

### А. Модуль «Личный журнал улик и рапортов» (`NOTES`)
- **Доступ**:
  - Кнопка `📁 ЛИЧНЫЙ ЖУРНАЛ [N]` в левой панели в разделе `ОПЕРАТИВНЫЕ МОДУЛИ` со счётчиком сохранённых записей.
  - Консольная команда `notes` (или `log` / `journal`) для быстрого открытия модуля из командной строки.
- **Структура записи**:
  - **Заголовок / Код записи** (например, *«Зацепка по сектору 4»* или *«Частота 88.2 МГц»*).
  - **Категория (тег)**: `УЛИКА`, `РАПОРТ`, `КОД / ЧАСТОТА`, `ПЕРСОНА`, `ПРОЧЕЕ`.
  - **Сектор / Сессия** (необязательное поле для пометки номера сессии или локации).
  - **Текст записи** (полноценное поле ввода с моноширинным форматированием).
  - **Штамп времени** (автоматическая дата и время создания/редактирования в формате терминала).
- **Возможности для игроков**:
  - Создание, просмотр, редактирование и удаление собственных записей.
  - Фильтрация по категориям (`ВСЕ`, `УЛИКА`, `РАПОРТ`, `КОД / ЧАСТОТА`, `ПЕРСОНА`) и мгновенный поиск по тексту/заголовку.
  - **Экспорт и импорт (`.json` / `.txt`)**: возможность скачать свой журнал файлом после сессии или загрузить обратно (полезно при смене браузера или для обмена рапортами между игроками).
  - Все данные хранятся локально в `localStorage` (`nadir_player_journal_v1`) и не содержат предзаписанных сюжетных спойлеров.

### Б. Тумблер цвета люминофора (`P1 ЗЕЛЁНЫЙ` ⇄ `P3 ЯНТАРНЫЙ`)
- **Визуализация**:
  - Переключатель в нижней статусной строке терминала (рядом с тумблером фонового звука): `[ ЛЮМИНОФОР: P1 ЗЕЛЁНЫЙ ]` / `[ ЛЮМИНОФОР: P3 ЯНТАРНЫЙ ]`.
  - Поддержка консольной команды `phosphor` (или `amber` / `green`) для переключения с клавиатуры.
- **Техническая реализация**:
  - Динамическое переключение CSS-переменных корневого элемента (`--bg`, `--green`, `--green-bright`, `--green-dim`, `--line`, `--glow`) и палитры Canvas-осциллографа радиоприёмника.
  - Короткий визуальный импульс перемагничивания ЭЛТ-трубки и сухой аппаратный щелчок при переключении.
  - Сохранение выбранного режима в `localStorage` (`nadir_phosphor_mode`).

### В. Режим ожидания ЭЛТ-терминала с помехами (`STANDBY`)
- **Логика срабатывания**:
  - Автоматический переход в режим ожидания после **90 секунд** отсутствия активности (движений мыши, кликов, нажатий клавиш). Если в радиоприёмнике открыта и играет станция или идёт взлом `INTERCEPT`, таймер не прерывает работу.
  - Принудительный запуск в любой момент через консольную команду `standby` (или `sleep`) либо кликом по индикатору статуса в футере.
- **Атмосферное оформление**:
  - Экран плавно гаснет до тёмного состояния дежурного накала с плавающей технической плашкой (`РЕЖИМ ОЖИДАНИЯ // ОЖИДАНИЕ ВВОДА ОПЕРАТОРА`, текущее системное время и уровень сигнала).
  - По экрану медленно проходит широкая полоса кадровой развёртки, а раз в несколько секунд пробегает короткий импульс «белого шума» и горизонтального смещения строк (glitch).
  - Любое движение мыши, клик или нажатие клавиши мгновенно пробуждает терминал с характерной короткой вспышкой кинескопа.

## 3. Затрагиваемые файлы и ограничения
- **`/index.html`**:
  - Добавление стилей янтарного люминофора (`body.phosphor-amber`), оверлея режима ожидания (`#standbyOverlay`) и интерфейса бортового журнала.
  - Добавление логики CRUD для `ЛИЧНЫЙ ЖУРНАЛ`, экспорта/импорта JSON, переключателя люминофора и таймера бездействия.
  - Обновление справки `help` в консоли новыми командами (`notes`, `phosphor`, `standby`).
- **Сохранность контента**:
  - Все существующие тексты досье, засекреченные блоки (только у Дариуса, Ящерки и Феликса), радиостанции, сообщения почты и сайты Ахерона/Нахтвахтера остаются строго без изменений.
